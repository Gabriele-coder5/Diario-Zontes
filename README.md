# Diario Zontes con sincronizzazione facoltativa

Sito statico senza spese incorporate. I dati restano nel dispositivo finché non viene configurato un progetto Supabase e collegato un accesso personale. Le policy del database devono essere attivate prima dell’uso.

Per usare la sincronizzazione apri il diario su Safari o Chrome, premi Sincronizzazione e accedi allo stesso account del diario su entrambi i dispositivi. Il primo collegamento chiede quale copia utilizzare. Non caricare nel repository backup, password o chiavi secret/service_role.
