Importa il backup

Il tuo diario, sempre con te

  1. Apri il file dal computer. Scarica Diario-Zontes.html e aprilo con Chrome, Edge o Firefox. Funziona senza connessione e senza accedere a ChatGPT.
  2. Aggiungi le spese. Il browser prova a ricordare le modifiche automaticamente. Usa lo stesso browser e lo stesso file per ritrovarle. La navigazione privata, la pulizia dei dati o lo spostamento del file possono far perdere questa memoria.
  3. Conserva il diario completo. Dopo aver aggiornato i dati, premi “Salva diario completo”. Verrà scaricato un nuovo file HTML contenente l’app e tutte le spese attuali. La copia precedente non viene modificata automaticamente. Conserva la copia più recente, anche su una chiavetta o in una cartella di backup.
  4. Trasferisci i dati. “Esporta backup” salva solo i dati in JSON. “Importa backup” accetta anche i backup del primo diario online. I dispositivi non si sincronizzano automaticamente.
  5. Su iPhone. Apri l’indirizzo web del diario in Safari, quindi Condividi → Aggiungi alla schermata Home → Apri come app web. Dopo la prima apertura online, attendi “Disponibile offline”. Puoi modificare spese e aspetto dall’iPhone. Il file HTML aperto dall’app File è solo un’anteprima: usa la versione web per i comandi.
  6. Dal PC all’iPhone. Esporta il backup, trasferiscilo con File/iCloud Drive o AirDrop e importalo dal diario aperto su iPhone. Per ritrovare i dati usa sempre la stessa app web. La cancellazione dei dati del browser può eliminare anche la copia offline: conserva i backup.
  7. I tuoi dati restano tuoi. Il diario non invia informazioni in rete. Chi possiede una tua copia del file o del backup può leggerne il contenuto.

Codice e risorse

Tutto il codice è aperto e modificabile. Nel pacchetto dei sorgenti trovi HTML, CSS, JavaScript e le icone separati. Il file unico contiene gli stessi elementi, senza servizi esterni.

Per modificare colori, font e icone usa Personalizza. Il codice HTML completo è modificabile; su iPhone usa Scarica codice per esportarlo. Per aggiornare il programma online bisogna ripubblicare i file su GitHub.
